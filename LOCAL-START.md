# Как пользоваться приложением

## 1. Откройте приложение

1. Откройте папку `C:\VK`.
2. Дважды нажмите **start-local.cmd**. Оставьте открывшееся окно работающим.
3. Страница приложения откроется сама. Если этого не произошло, откройте браузер и перейдите на [http://127.0.0.1:5000](http://127.0.0.1:5000).

Если приложение уже работает, достаточно открыть эту ссылку — запускать его второй раз не нужно.

## 2. Скачайте переписку

1. Откройте приложение в том же браузере, где вы вошли в ВК.
2. Нажмите **«Скачать диалог»** в меню, затем **«Подключить браузер»**. Выполните шаги на открывшейся странице. Если написано «Браузер подключён», этот шаг уже сделан.
3. На сайте ВК откройте нужную переписку. Нажмите **Ctrl+L**, затем **Ctrl+C**, чтобы скопировать ссылку на неё.
4. Вернитесь в приложение. Нажмите на поле **«Ссылка на диалог»** и нажмите **Ctrl+V**.
5. Нажмите кнопку **«Скачать диалог»** под полем ссылки. Дождитесь завершения и нажмите **«Открыть переписку»**.

Пока идёт скачивание, оставьте компьютер, окно приложения и браузер с ВК включёнными. Для каждого нового диалога повторите шаги 3–5.

## 3. Читайте сохранённые сообщения

- Откройте **«Диалоги»** и нажмите на имя собеседника.
- Найдите нужное сообщение через поиск или выберите дату.
- Нажмите фотографию, чтобы увеличить её. Сохранённые видео и аудио можно включать прямо в переписке.
- Нажмите **«Показать вложения»**, чтобы увидеть все сохранённые файлы этого диалога.

Сохранённую переписку можно читать без интернета. Для скачивания новых сообщений нужен интернет и открытый ВК.

## Настройки и остановка

В **«Настройках»** выберите, скачивать ли видео, музыку и голосовые сообщения. Нажмите **«Сохранить настройки»**. Фото, стикеры и доступные документы сохраняются автоматически.

Чтобы остановить приложение, нажмите **Ctrl+C** в его окне. Для фонового сервера используйте **stop-local.cmd**. Скачанные диалоги остаются на компьютере.

### Где лежат файлы

Папка архива выбирается в настройках приложения. Приведённые ниже пути отсчитываются от неё.

- Исходные сообщения: `ExportMessages\Sources` и `ExportMessages\Dialogs\…\OriginalMessages`.
- Подготовленные сообщения и небольшие вложения: `ExportMessages\Dialogs`.
- Видео и общие медиафайлы: `LargeRawData`.

Точная папка хранения указана в **«Настройки → Расширенные настройки»**. При её смене старые файлы нужно перенести вручную.

### Если не скачалось вложение

Откройте предупреждения под результатом скачивания: там указаны сообщение и причина ошибки. Недоступные файлы не всегда можно восстановить. Видео с YouTube остаются ссылками в сообщениях.

Для ранее сохранённых сообщений есть **«Настройки → Расширенные настройки → Скачать недостающее аудио»**. Сначала включите музыку и/или голосовые сообщения и сохраните настройки. Программа попробует скачать отсутствующее аудио по ссылкам из архива.

Точные копии медиа объединяются автоматически. Один общий файл может использоваться в нескольких сообщениях или диалогах.

### Ручная работа

На странице скачивания раскройте **«Дополнительно: ручная выгрузка и работа с файлами»**, если у вас уже есть JSON-файл сообщений или нужен способ без помощника браузера.

Для переименования, перемещения и удаления файлов откройте **«Дополнительно → Редактор файлов»** внутри диалога. Изменения влияют на локальный архив.

Подробности установки новой копии, настройки браузеров и устройства проекта находятся в [README.md](README.md).
