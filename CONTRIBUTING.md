# Участие в разработке

Для ошибки или идеи используйте формы [Issues](https://github.com/Alexshvd/vk-chat-backup-pro/issues/new/choose). Не публикуйте личные архивы; правила — в [SUPPORT.md](SUPPORT.md).

Для изменения кода:

1. Создайте ветку от `main` и свяжите изменение с задачей.
2. Сохраняйте совместимость синтаксиса с Python 3.9; инструкции по проекту находятся в AGENTS.md.
3. Запустите подходящие проверки. Полный набор:

```sh
python -m unittest discover -s tests -q
node --test tests/test_chrome_helper.cjs tests/test_browser_detect.cjs tests/test_export_status.cjs tests/test_media_library.cjs tests/test_settings_media.cjs
```

4. В Pull Request объясните проблему, новое поведение и выполненные проверки. `Fixes #123` связывает исправление с задачей; для частичного исправления используйте `Refs #123`.

Не включайте личный config.json, Temp/, выгрузки диалогов, журналы, cookies и токены. Изменения выпускаются под MIT с сохранением уведомлений об авторстве.

## Версии

Приложение и расширение имеют независимые версии. `1.0.0-beta.1` — первый тестовый выпуск приложения; `1.0.0` будет стабильным выпуском после проверки. Исправления увеличивают третье число, новые совместимые возможности — второе. Версию расширения повышайте при его изменении; не уменьшайте числовую версию манифеста. Метаданные приложения находятся в app_info.py, расширения — в BrowserExtension/manifest.json.
