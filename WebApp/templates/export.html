Экспорт сообщений

1. Как получить messages.json

Для создания MD-файлов необходимо вручную выгрузить сообщения из VK. Скрипт ниже имитирует вызов API VK (загрузка истории диалога) и сохраняет результат в JSON-файл.

  1. Откройте сайт VK в браузере и войдите в аккаунт (vk.com, vk.ru). Откройте интересующий диалог
  2. Откройте консоль браузера (ПКМ → Исследовать элемент → Console, F12 → Console или Ctrl+Shift+J)
  3. Настройте параметры ниже.
    Peer ID обязателен — скопируйте его из адресной строки, открыв нужный диалог (например https://vk.ru/im/convo/123456789, число в конце адресной строки)
  4. Выгрузка сообщений
    • Скопируйте скрипт с помощью кнопки справа
    • Вставьте скрипт в консоль
    • Нажмите Enter

    После запуска скрипта начнётся загрузка истории диалога — это может занять несколько минут. По завершении автоматически скачается JSON-файл с сообщениями.

2. Подключение messages.json

Переместите скачанный JSON-файл в папку Sources — директорию для хранения сообщений, путь к которой указан в конфиге. Переместить файл можно вручную или с помощью кнопки ниже.
