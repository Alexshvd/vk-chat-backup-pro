VK не предоставляет удобного способа сохранить историю диалога целиком — вместе с фото, видео, стикерами и документами. **VkChatBackup** решает эту задачу: выгружает сообщения, конвертирует их в Markdown и скачивает все вложения.

Приложение полностью локальное — данные (исходные JSON, медиафайлы, Markdown-документы) остаются только на вашем компьютере и не передаются на внешние сервисы. Управление происходит через веб-редактор в браузере.

![Скриншот веб-редактора](docs/screenshots/editor.png)

**Возможности:**
- Все типы вложений: фото, видео (mp4 + fallback VK Player), стикеры, документы, ссылки, аудио, записи на стене, пересланные сообщения
- Авторы с аватарами и типом (пользователь / сообщество)
- Фильтры `min_cid` и `min_date` при экспорте
- Веб-редактор: конвертация, просмотр, переименование, удаление, группировка по папкам, массовые операции
- Полностью офлайн

## Быстрый старт

1. Установите Python 3.9+ и зависимости:

   ```sh
   pip install -r requirements.txt
   ```

2. `config.json` уже есть в проекте — при необходимости отредактируйте (страница «Настройки» или вручную)
3. Запустите веб-редактор:

   ```sh
   python run.py --mode web --config config.json
   ```

4. Откройте `http://127.0.0.1:5000`

**Как предстоит работать:**

1. **Выгрузка сообщений** — вручную через консоль браузера (скрипт формируется на странице «Экспорт»)
2. **Конвертация** — сообщения превращаются в Markdown, вложения скачиваются на диск
3. **Управление** — через веб-редактор: просмотр, переименование, удаление, группировка по папкам

Внутри веб-редактора есть подробная пошаговая инструкция (главная страница и страница «Экспорт») — следуйте ей.

## Рекомендации

- **Располагайте проект выше в иерархии.** Лимит длины пути — 254 символа: чем короче путь, тем больше места остаётся именам файлов
- **Используйте подпапки и сортировку** для группировки сообщений
- **Храните результат в отдельном месте** — например, в приватном репозитории (автор хранит на GitHub)
- **Удаляйте мусор через веб-редактор** — доступны удаление, переименование, массовое переименование и перемещение файлов
- **При перемещении ссылки заменяются автоматически** — перемещайте файлы только через веб-редактор
- **Не перемещайте файлы вручную** в файловом менеджере — слетят относительные ссылки
- **Не переименовывайте файлы вручную** — имена содержат важную информацию (например, cid сообщения)
- **Вложения переименовывайте тоже через редактор** — так ссылки в MD обновляются
- **Не удаляйте файлы вложений вручную** — удаление делается в редакторе
- **Храните исходные JSON в `Sources/`** как бэкап — пригодится для повторной конвертации
- **Пользуйтесь фильтрами `min_cid` / `min_date`**, чтобы не выгружать старые сообщения

## FAQ

**Как добавить сообщения к уже существующему диалогу?**
Скачайте новый `messages.json` с более новыми сообщениями, поместите в `Sources/` и задайте фильтр `min_cid` / `min_date` на странице «Экспорт» — повторная конвертация добавит только новые сообщения.

**Как добавить новый диалог?**
Скачайте `messages.json` для другого диалога (другой `peer_id`) и поместите в `Sources/`.

**Как переконвертировать диалог заново?**
Включите флаги `overwrite_existing_md` и `overwrite_existing_original_message_json` на странице «Экспорт» (или в `config.json`).

**Как полностью удалить сообщение?**
В веб-редакторе удаление убирает MD-файл, вложения `RawData`/`LargeRawData` и исходный JSON.

**Как переименовать папку диалога?**
На странице диалога — кнопка ✏ рядом с названием папки.

**Что за ограничение 254 символа?**
Windows не допускает пути длиннее 254 символов. Длина учитывается для имён MD-файлов и вложений.

**Где взять peer_id?**
В адресной строке диалога: `https://vk.ru/im/convo/{peer_id}`.

**Что означает «Ошибка скачивания» в таблице «Источники»?**
Вложение скачать не удалось (сетевой сбой, ограничения VK). В файле осталась только ссылка на оригинал.

**Где хранятся вложения пересланных сообщений?**
В `RawData/{root_cid}/{fwd_cid}/` — внутри каталога корневого сообщения.

**Структура файлов**

```
{export_root}/
├── ExportMessages/
│   ├── Sources/                              # Исходные JSON-файлы сообщений
│   │   └── messages.json
│   └── Dialogs/
│       ├── AutorImages/                      # Аватары авторов
│       │   └── photo_12345.jpg
│       └── dialog_{peer_id}/ (или {custom_name})
│           ├── RawData/                      # Малые вложения (фото, стикеры, доки)
│           │   └── {cid}/
│           │       ├── 1.jpg
│           │       └── 2.webp
│           ├── OriginalMessages/             # Исходные JSON по одному сообщению
│           │   └── 2026-01-15_1234.json
│           └── MdFiles/                      # Сконвертированные Markdown-файлы
│               └── Привет.Id1234.md
└── LargeRawData/                             # Большие файлы (видео)
    └── dialog_{peer_id}/
        └── {cid}/
            └── 1.mp4
```
