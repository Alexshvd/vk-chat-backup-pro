## Store listing

**Название:** VK Chat Backup Pro — помощник

**Краткое описание:** Сохраняйте выбранную переписку ВК в локальное приложение VK Chat Backup Pro на своём компьютере.

**Категория:** Productivity (если она доступна в текущем кабинете).

**Язык:** русский.

**Подробное описание:**

> Бесплатный помощник для локального приложения VK Chat Backup Pro. Получает историю выбранного вами диалога ВК и передаёт её приложению на вашем компьютере для сохранения сообщений и доступных вложений.
>
> Как пользоваться:
> 1. Скачайте локальное приложение по ссылке на сайт проекта, распакуйте и запустите его.
> 2. Откройте приложение в браузере, где вы вошли в ВК.
> 3. Нажмите «Подключить браузер» и подтвердите подключение помощника.
> 4. Вставьте ссылку на нужный диалог и нажмите «Скачать диалог».
>
> Помощник работает вместе с локальным приложением и требует действующего входа в ВК. Пароль и cookies не копируются. История передаётся локально на ваш компьютер; у разработчика нет сервера сбора переписок. Доступность сообщений и качество медиа зависят от данных, которые возвращает ВК. Видео YouTube сохраняются ссылками.
>

## Privacy practices

**Single purpose:** Получение выбранной пользователем истории диалога ВК и передача в подключённое локальное приложение для создания личного архива.

**Обоснования разрешений:**

| Разрешение | Обоснование для формы |
| --- | --- |
| scripting | Запускает функцию чтения messages.getHistory в выбранной вкладке ВК. Функция входит в пакет расширения. |
| storage | Сохраняет адрес локального приложения и токен, выданный при подключении. |
| alarms | Периодически проверяет задания подключённого приложения и восстанавливает связь после перезапуска фонового процесса. |
| Host permissions: домены ВК | Находит вкладку выбранного диалога и выполняет получение истории в текущей сессии. |
| Host permissions: localhost / 127.0.0.1 | Подключается к приложению на том же компьютере, получает задания и передаёт результаты. Произвольный порт нужен для пользовательского --port. |

**Remote code:** Нет. JavaScript поставляется в ZIP; eval, внешние скрипты и загружаемый исполняемый код не используются.

**Категории данных:** отметьте «Personally identifiable information» (имена, идентификаторы и профильные сведения), «Personal communications» (сообщения и пересылки), «Website content» (данные страницы/ответа ВК и вложения) и «Authentication information» (собственный токен связи с локальным приложением, не пароль и не cookies ВК). Если форма содержит «Web history», раскройте ограниченную обработку текущих адресов вкладок ВК для поиска выбранного диалога; история посещений не собирается. Сопоставьте эти описания с точными определениями полей в кабинете перед отправкой.

**Декларации использования:** данные не продаются; используются только для заявленной функции архива; не используются для кредитоспособности или кредитования. Требования Limited Use отражены в политике.

## Инструкция для проверяющего

1. Скачать Windows-сборку последнего beta-релиза с GitHub Releases и распаковать в обычную папку.
2. Запустить VkChatBackupPro.exe; локальная страница открывается на 127.0.0.1:5000.
3. Использовать собственный тестовый аккаунт ВК и диалог с вымышленными сообщениями. Чужие реальные данные и учётные данные разработчика не предоставляются.
4. Установить пакет помощника, открыть приложение в том же браузере и нажать «Подключить браузер».
5. Для проверки потоковой музыки HLS установить FFmpeg скриптом из Windows-комплекта и перезапустить приложение. Для остальных проверок он не нужен.
6. Вставить ссылку на тестовый диалог и запустить выгрузку. История и вложения появятся в папке приложения; проверить просмотр в «Диалоги».
7. Закрыть приложение: помощник перестаёт получать задания; можно снова запустить сервер.
