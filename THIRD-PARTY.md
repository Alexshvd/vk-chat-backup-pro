# Сторонние компоненты Windows-комплекта

Исходный код VK Chat Backup Pro распространяется под MIT; уведомления об авторстве находятся в LICENSE.md. У включённых зависимостей собственные лицензии: они скопированы из установленных пакетов в папку ThirdPartyLicenses в Windows ZIP. Там же находится лицензия включённого Python. PyInstaller распространяет загрузчик с исключением для собранных приложений; его лицензия также включена.

В сборке используются Python, Flask и его зависимости, requests и его зависимости, mistune, m3u8, PyCryptodome, а также Python-обёртка imageio-ffmpeg. Перечень и версии прямых зависимостей закреплены в requirements.txt.

## FFmpeg для потоковой музыки

Исполняемый файл FFmpeg не входит в публичный Windows ZIP первого beta-выпуска. Обёртка imageio-ffmpeg распространяется под BSD-2-Clause и ищет отдельно установленный FFmpeg в PATH или по IMAGEIO_FFMPEG_EXE.

Чтобы сохранять HLS-аудио, запустите **«Установить FFmpeg.cmd»** из папки приложения. Скрипт вызывает Windows Package Manager для пакета `Gyan.FFmpeg.Essentials`; условия источника и пакета подтверждает пользователь. После установки перезапустите приложение. Альтернативный источник: [сборки Gyan](https://www.gyan.dev/ffmpeg/builds/), указанные на [сайте FFmpeg](https://ffmpeg.org/download.html).

Сборки Gyan имеют собственную лицензию GPLv3. Их исходники и лицензия предоставляются издателем сборки; это отдельная установка пользователя. Для прямых MP3/OGG, фотографий и MP4 FFmpeg не требуется. Локальная разработческая установка imageio-ffmpeg может содержать свой FFmpeg; она не включается целиком в публичный релиз.
