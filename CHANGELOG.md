# Изменения форка

Этот файл описывает изменения относительно [saigor33/vk-chat-backup](https://github.com/saigor33/vk-chat-backup). Возможности исходного проекта перечислены в [README_UPSTREAM.md](README_UPSTREAM.md).

## Unreleased

Последующие изменения будут перечислены здесь.

## 1.0.0-beta.1 — 2026-10-05

Первый тестовый выпуск VK Chat Backup Pro. Помощник браузера — 1.1.1. Версии приложения и расширения независимы.

- Официальный GitHub-форк с сохранённой историей разработки и авторством оригинала.
- Формы ошибок и предложений, ссылки на поддержку и версия в интерфейсе.
- Общие стили меню, карточек, кнопок, полей и раскрывающихся блоков основных страниц.
- Аватары в списке сохранённых диалогов.
- Политика конфиденциальности, инструкция поддержки и материалы для Chrome Web Store.
- Windows-комплект с нейтральными настройками, лицензиями зависимостей и отдельные ZIP-пакеты помощника. FFmpeg для HLS-музыки устанавливается отдельно скриптом из комплекта.

### Добавлено

- Библиотека вложений каждого диалога: фото, видео, аудио и документы, фильтры, поиск, размеры файлов и переходы к сообщениям. Общий файл показывается одной карточкой.
- Объединение точных копий медиа по SHA-256 с обновлением ссылок в сообщениях и поддержкой общих файлов в просмотрщике и редакторе.
- Подробности предупреждений: сообщение, название вложения, адрес, путь и причина ошибки. Для прежних журналов доступны сведения из сохранённого архива.

- Повторное использование видео между диалогами: индекс ID ВК и качества, быстрый повторный скан, общее хранилище без повторного скачивания, поддержка прежних выгрузок и догрузки видео.
- Защита общих видео при удалении или перезаписи исходного сообщения; отображение общих файлов и их размеров в редакторе.

- Автоматическое определение текущего браузера и подходящих инструкций помощника. Подключение открывается в той же вкладке, без выбора браузера и запуска отдельного приложения.
- Общая логика помощника для Chromium и Firefox, отдельные ZIP-сборки с подходящими манифестами, инструкции для разных браузеров.
- Подключение помощника к текущему порту локального сервера вместо фиксированного порта 5000; сохранена совместимость существующего подключения на 5000.
- Ручная выгрузка JSON для браузеров без готового помощника, включая Safari.
- Исходники помощника включены в скрипт сборки PyInstaller.


- Выгрузка диалога по ссылке: получение полной истории с пагинацией, автоматическое сохранение JSON и запуск обработки сообщений и вложений.
- Расширение `BrowserExtension` для работы через подключённый браузер и существующий вход в ВК.
- Разовое подключение помощника к локальному приложению, проверка подключения и авторизация запросов. Коды подключения одноразовые, на сервере сохраняются хеши ключей.
- Фоновые задачи с сохранением статуса, количества полученных сообщений, журнала, прогресса текущего файла и кнопкой остановки. Задачи продолжаются при закрытии вкладки приложения и перезапуске веб-сервера.
- Просмотр архива как переписки: входящие и исходящие сообщения, авторы, ответы, пересылки, вложенные записи на стене, изображения, документы, видео и аудио.
- Поиск по истории и пересылкам, переход к дате, подгрузка предыдущих сообщений, увеличение фотографий и обновление архива с сохранением позиции.
- Отдельные настройки скачивания музыки и голосовых сообщений.
- Поддержка голосовых MP3/OGG, старых голосовых в документах и доступного HLS-аудио, включая поддерживаемые зашифрованные сегменты. Поток сохраняется в M4A через FFmpeg.
- Догрузка аудио в существующий архив через настройки с сохранением предыдущих версий изменённых MD.
- Автоматическая проверка размера сохранённых фото и замена уменьшенных копий при повторной генерации. Прежние фото и изменённые MD сохраняются в `PhotoBackups`.
- Восстановление пропущенных видео в существующих сообщениях с резервными копиями MD в `VideoBackups`.
- Параллельная загрузка крупных MP4 по диапазонам, кэш завершённых частей и продолжение при повторной попытке для того же файла и ссылки.
- Локальный запуск без отладчика и автоматического перезапуска: `run-local.py`, `start-local.cmd`, `stop-local.cmd`, `stop-local.ps1`.
- 59 тестов Python и 13 тестов JavaScript для новых возможностей и исправлений.
- Пример публичной конфигурации без личных названий и идентификаторов диалогов.

### Исправлено

- Ранние предупреждения больше не исчезают после 40 строк прогресса: они сохраняются отдельно и показаны в блоке «Предупреждения». Итоговый статус не приравнивает любое предупреждение к несохранённому вложению.
- Проверка фото теперь повторно скачивает изображения с отметкой «Ошибка скачивания», восстанавливает локальные ссылки и сохраняет резервную копию изменённого MD. В итог добавлен отдельный счётчик восстановленных фото.

| Проблема | Результат |
| --- | --- |
| У старых фотографий все `width` и `height` равны нулю, поэтому выбиралась первая миниатюра. | При отсутствии размеров учитывается тип копии ВК; выбирается наибольшая доступная версия. |
| Уже созданные MD пропускаются, поэтому исправление выбора фото не меняло старые файлы. | Проверка существующих фото выполняется отдельно и обновляет файл по прежнему пути. |
| Некоторые MP4 не выбирались из-за ограниченного списка разрешений или отсутствия обработки `src`. | Поддерживаются числовые ключи `mp4_*` и прямая ссылка `src`; выбирается наибольшее разрешение. |
| Скачивание видео могло обрываться на одном CDN. | Добавлена поддержка резервного хоста, если он передан в данных видео. Недоступные ссылки по-прежнему отражаются в журнале. |
| Ошибочный или неполный ответ на запрос диапазона мог повредить видео. | Проверяются диапазон, длина части, ETag при его наличии и итоговый размер; целевой файл заменяется после успешной сборки. |
| Имена MD могли превышать лимит полного пути Windows. | Длина рассчитывается в UTF-16 с учётом каталога, расширения, идентификатора и дополнительных суффиксов. |
| Неполная или повторяющаяся страница истории могла приводить к частичному экспорту. | Проверяются полнота истории и повторение страниц; обработка архива начинается после получения всей истории. |

### Изменено

- Основной сценарий на странице экспорта — ссылка на диалог и кнопка **«Скачать диалог»**. Ручной способ перенесён в раскрывающийся блок.
- Главная страница и инструкции переписаны простыми словами. На основных экранах остаются скачивание и просмотр; технические параметры, ручная выгрузка и редактор файлов доступны под «Дополнительно» или «Расширенные настройки».
- Основные настройки скачивания — видео, музыка и голосовые сообщения. Выбор видео по длительности сохранён в расширенных настройках.
- Кнопка подключения учитывает состояние браузера и загрузки: уже подключённый браузер не предлагается подключать повторно.
- Подключение ВК работает через подключённый обычный браузер. Автоматический выбор Edge и отдельный профиль браузера удалены.
- Список диалогов ведёт в просмотрщик переписки; прежний редактор доступен отдельно.
- При выгрузке по ссылке существующие сообщения и извлечённые JSON сохраняются независимо от настроек перезаписи.
- В локальном статусе импорта сохраняются подробности ошибок и подписанные ссылки на вложения. Учётные токены скрываются; браузерные cookies и пароль не копируются.
- README описывает текущий форк, сценарии использования и ограничения. Описание оригинала сохранено отдельно.
- В лицензию добавлено `Copyright © 2026 Aleksei Shvedov`; строка `Copyright © 2024 Skladchikov Igor` и исходный текст MIT сохранены.

### Проверено

- Автоматические проверки: 70 тестов Python и 23 теста браузерных скриптов прошли при подготовке изменений. Сохранение настроек с закрытым расширенным разделом проверено на временной копии конфигурации.
- Выгрузка истории через текущий Chrome проверена на реальном диалоге, включая получение всей истории и повторное использование уже сохранённых сообщений.
- Проверка локального архива обнаружила и заменила уменьшенные фотографии. Полученные файлы проверены по размерам; один из исправленных JPEG дополнительно полностью декодирован FFmpeg.
- Повторный запуск проверки фото после исправления не скачивал их заново.

Эти проверки относятся к локальной конфигурации разработки. Они не гарантируют доступность каждого вложения или одинаковую скорость на других компьютерах.

- Дополнительно проверены автоматическое определение браузера, отсутствие запуска отдельного браузера, Firefox API в тестовом окружении, манифесты двух сборок и подключение на другом локальном порту. Реальные запуски всех перечисленных браузеров отдельно не подтверждались.

- Проверено повторное использование при изменении подписанных ссылок, разные владельцы с одинаковым ID, качество, повреждённые/неполные файлы, перезапись сообщений, удаление первого диалога, перенос MD и архива, Range-запросы плеера и файловая система без жёстких ссылок.
